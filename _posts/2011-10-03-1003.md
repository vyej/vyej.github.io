其實想做的是python基礎知識地圖——本來圖譜或思維導圖什麼的好像更準確一些，大抵也就是這個意思。導圖什麼的其實也是更容易有一個整體的觀點，所以其實地圖的比喻也不錯啊。至少知道有什麼，可以去找什麼。

**Magnus Lie Hetland的《Python基础教程》以及Eric Matthes的Python编程：从入门到实践**

	- 基础知识

	- 使用字符串
	- 字典
	- 条件、循环及其他语句
	- 抽象：函数、参数、作用域
	- 再谈抽象：对象、类
	- 异常
	- 魔法方法、特性和迭代器
	- 开箱即用：模块、标准库
	- 文件
	- 图形用户界面
	- 数据库支持
	- 网络编程
	- Python 和 Web
	- 测试基础
	- 扩展 Python
	- 程序打包
	- 趣味编程
	- 项目
